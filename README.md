## 🚀 Netlify Deployment Options (100% Ready)

This portfolio is configured with `netlify.toml` and `_redirects` for instant zero-configuration deployment to Netlify:

### Method 1: Instant Drag-and-Drop (No Git / CLI required)
1. Navigate to **[app.netlify.com/drop](https://app.netlify.com/drop)** in your browser.
2. Drag and drop the `dist` folder located at:
   `C:\Users\ACER\Documents\jabir-jalal-portfolio\dist`
3. Netlify will deploy your portfolio in ~10 seconds with a free `.netlify.app` URL and SSL certificate!

### Method 2: 1-Click Deployment Batch Script
Double-click the included batch file:
`C:\Users\ACER\Documents\jabir-jalal-portfolio\DEPLOY_NETLIFY.bat`
- Option 1 builds and deploys directly via Netlify CLI (`npx netlify deploy --prod`).
- Option 2 opens the browser to Netlify Drop and opens the `dist` folder in File Explorer.

### Method 3: Continuous Deployment via GitHub
1. Push this repository to GitHub: `https://github.com/jabirjalal12/jabir-jalal-portfolio`
2. Log into Netlify, click **"Add new site"** → **"Import an existing project"** → select your GitHub repository.
3. Netlify automatically reads `netlify.toml`:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `dist`
4. Every push to GitHub will automatically trigger a production deployment.
